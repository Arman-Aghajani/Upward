Problem 2 — Binary Search

The Problem

Write a function called binary_search that takes a sorted list and a target value. It must return the index of the target if found, or -1 if not. You cannot use linear search or any built-in search function — you must implement the binary search algorithm correctly.

binary_search([1,3,5,7,9,11], 7) → 3
binary_search([1,3,5,7,9,11], 6) → -1
binary_search([2], 2) → 0
binary_search([], 5) → -1

Your solution must run in O(log n) time — meaning the number of steps must halve with each iteration, not grow linearly.

💡 Hint: Think about maintaining a left and right boundary, and repeatedly checking the middle element to decide which half to eliminate.
