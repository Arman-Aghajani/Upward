Problem 1 — Recursive Factorial

The Problem

Write a function called factorial that takes a non-negative integer and returns its factorial using recursion only. No loops of any kind are allowed.

factorial(0) → 1
factorial(1) → 1
factorial(5) → 120
factorial(10) → 3628800

Your function must call itself. It must also handle the base case correctly or it will loop forever.

💡 Hint: Every recursive function needs two things — a case where it stops, and a case where it calls itself with a smaller version of the problem.
