Tuples
Defined with parentheses: (1, 2, 3). Immutable — once created, can't change. Faster than lists. Used for fixed data: coordinates, RGB colors, database rows. Can be used as dict keys (lists can't). Unpack easily: x, y = (10, 20).
🎯
When to use tuples
Use tuples when data should not change — return values from functions, config constants, coordinates. The immutability signals intent: "this is fixed data, don't modify it."
Sets
Defined with curly braces: {1, 2, 3}. No duplicates — adding an existing element does nothing. No indexing (unordered). Extremely fast membership testing with in. The classic use case: removing duplicates from a list with list(set(my_list)).
Set operations

all elements from both

⚠️
Empty set gotcha
{} creates an empty dict, not a set. To create an empty set you must use set(). This is one of Python's few inconsistencies.
Tuple analogy: A tuple is like GPS coordinates — (lat, lon). The values have meaning in their position and should never change.

Set analogy: A set is like a bag of unique lottery numbers. Order doesn't matter, and you can't have the same number twice.
