Lesson 5 — Lists

A list is an ordered collection of items. Lists can hold any type of data — numbers, strings, or even other lists. They are one of the most used data structures in Python.

CREATING & ACCESSING Lists use square brackets [ ]. Each item has an index starting at 0. You can access items with list[index]. Negative indexes count from the end — list[-1] is the last item.
SLICING You can get a portion of a list using list[start:end]. The start is included, the end is excluded. Leaving start or end blank means from the beginning or to the end.
COMMON METHODS
append(x)Add x to end
remove(x)Remove first x
len(list)Get length
sort()Sort in place
pop(i)Remove at index
inCheck if exists
ITERATING Use a for loop to go through every item in a list. This is extremely common in real programs and competition problems.
Try It Yourself

Creating and accessing:

scores = [95, 82, 67, 100, 74]
print(scores[0])   # 95 (first)
print(scores[-1])  # 74 (last)
print(scores[1:3]) # [82, 67]

Common operations:

scores.append(88)    # add to end
scores.remove(67)    # remove value
scores.sort()        # sort ascending
print(len(scores))   # 5
print(100 in scores) # True

Looping through a list:

names = ["Alice", "Bob", "Charlie"]
for name in names:
    print("Hello,", name)

# Sum all scores
total = 0
for s in scores:
    total += s
print("Total:", total)
