Lesson 4 — Functions

A function is a reusable block of code that runs only when called. Instead of writing the same code multiple times, you write it once inside a function and call it whenever needed.

DEFINING A FUNCTION Use the def keyword, give it a name, and add parentheses. The code inside must be indented.
PARAMETERS Parameters are inputs you pass into a function. Inside the function, they act like variables. You can have multiple parameters separated by commas.
RETURN VALUES The return keyword sends a value back to whoever called the function. Without return, the function just runs its code and gives back None.
WHY USE FUNCTIONS? Functions make code cleaner, easier to debug and reusable. If you need to change logic, you only change it in one place instead of everywhere.
Try It Yourself

Basic function with no parameters:

def greet():
    print("Hello, warrior!")

greet()  # calling the function

Function with parameters and return:

def add(a, b):
    return a + b

result = add(10, 5)
print(result)  # prints 15

Real example — calculate grade:

def get_grade(score):
    if score >= 90:
        return "A"
    elif score >= 70:
        return "B"
    elif score >= 50:
        return "C"
    else:
        return "F"

print(get_grade(85))  # B
print(get_grade(42))  # F
