Lesson 6 — Strings

A string is a sequence of characters. In Python, strings are written inside quotes — single or double. Strings are one of the most important types in Python, especially for competition problems.

INDEXING & SLICING Strings work exactly like lists — each character has an index starting at 0. You can slice with s[start:end] and use negative indexes. s[::-1] reverses the string.
COMMON METHODS
upper()All uppercase
lower()All lowercase
strip()Remove spaces
split()Split to list
replace(a,b)Replace text
count(x)Count occurrences
find(x)Find index
startswith()Check prefix
F-STRINGS f-strings let you embed variables directly inside a string. Write f"..." and use {variable} inside. This is cleaner than concatenation with +.
STRINGS ARE IMMUTABLE You cannot change a character in a string directly. You must create a new string. This is why replace() returns a new string instead of modifying the original.
Try It Yourself

Indexing and slicing:

word = "Python"
print(word[0])     # P
print(word[-1])    # n
print(word[0:3])   # Pyt
print(word[::-1])  # nohtyP (reversed)

String methods:

s = "  Hello World  "
print(s.strip())          # "Hello World"
print(s.lower())          # "  hello world  "
print(s.replace("World", "Python"))
words = "a,b,c".split(",")
print(words)  # ['a', 'b', 'c']

f-strings and counting:

name = "Arman"
score = 99
print(f"Player {name} scored {score}!")

text = "banana"
print(text.count("a"))  # 3
print(text.find("n"))   # 2
