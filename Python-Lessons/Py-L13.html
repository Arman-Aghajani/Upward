L13 Dictionaries

A dictionary stores data as key-value pairs. Instead of accessing items by index, you access them by a meaningful key — like looking up a word in a real dictionary.

Structure
Dictionaries use curly braces with key: value pairs. Keys must be immutable (strings, numbers, tuples). Values can be anything — even other dicts or lists.
player = {"name": "Alex", "xp": 250, "rank": "B"}
"name"
→
"Alex"

🔑
Accessing & modifying
d["key"] gets a value — raises KeyError if missing. d.get("key", default) is safer — returns the default instead of crashing. Assign with d["key"] = value to add or update.

Iterating
for key in d loops over keys. for key, val in d.items() gives both. for val in d.values() loops over values only. Always use .items() when you need both.
⚡
Dict comprehensions
Just like list comprehensions but with curly braces and a colon: {k: v for k, v in pairs}. Powerful for transforming or filtering dictionaries in one line.
Analogy: A dictionary is like a contact book. You don't flip through page by page — you go directly to the name (key) and get the phone number (value) instantly.
example.py

2    "name": "Alex",

20# Dict comprehension — word counter
21words = ["hi", "bye", "hi", "hi", "bye"]
22count = {w: words.count(w) for w in set(words)}
23print(count)

⭐
Fun fact: Python dicts are implemented as hash tables — lookup by key is O(1) regardless of dict size. This is why checking "key" in d is instant even for a million-entry dict, while the same check on a list is O(n).
