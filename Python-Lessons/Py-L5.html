L5 For & While Loops

A loop repeats a block of code multiple times. Instead of writing the same line 100 times, you write it once and tell Python how many times to run it.

for loop
Iterates over a sequence — a list, a string, or a range(). For each item in the sequence, it runs the indented block once. You always know how many times it will run.
range()
Generates a sequence of numbers. The most common tool for controlling how many times a loop runs:
range(5)
0, 1, 2, 3, 4
range(2, 6)
2, 3, 4, 5
range(0, 10, 2)
0, 2, 4, 6, 8
range(5, 0, -1)
5, 4, 3, 2, 1
while loop
Runs as long as a condition is true. You don't always know how many times it will run — it stops when the condition becomes false. Use when the number of iterations is unknown.
break & continue
break exits the loop immediately, even if there are iterations left. continue skips the rest of the current iteration and jumps to the next one. Both work in for and while.
Iterating over strings & lists
A for loop can iterate directly over any sequence. for char in "hello" gives you each character. for item in my_list gives you each element.
⚠️ Infinite loop warning: A while loop whose condition never becomes false runs forever and crashes your program. Always make sure something inside the loop changes the condition.
Analogy: A for loop is like reading every page of a book — you know when it ends. A while loop is like waiting for a bus — you stop when it arrives, however long that takes.
example.py
1# for loop with range
2for i in range(5):
3    print(f"Step {i}")
4
5# for loop over a list
6ranks = ["E", "D", "C", "B"]
7for rank in ranks:
8    print(f"Rank {rank}")
9
10# while loop
11xp = 0
12while xp < 30:
13    xp += 10
14    print(f"XP: {xp}")
15
16# break and continue
17for n in range(10):
18    if n == 3: continue
19    if n == 6: break
20    print(n)

⭐
Fun fact: Python's for loop is actually a foreach loop under the hood — it always iterates over a sequence. There's no classic C-style for(i=0; i<n; i++) in Python. range() is how you simulate it.
