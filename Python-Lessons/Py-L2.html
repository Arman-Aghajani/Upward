L2 Variables &
Data Types

A variable is a named box that stores a value. You give it a name, assign a value with =, and use it anywhere in your code.

Creating a variable
Write a name, then =, then a value. No special keyword needed. Python figures out the type automatically.
The 4 basic types
Every value has a type. Python has 4 core ones you'll use constantly:
int age = 18
float price = 9.99
str name = "Alex"
bool active = True
Reassigning
You can change a variable's value anytime — just assign again. The old value is replaced instantly.
type()
type(x) tells you what type a variable is. Very useful for debugging when you're unsure what you're working with.
Analogy: A variable is like a labeled jar. You write a name on it, put something inside, and can always replace the contents later.
