L10 Lists & Indexing

A list is an ordered, mutable collection of items. Unlike strings, lists can be changed in place — you can add, remove, and modify items freely.

📋
Creating lists
Lists use square brackets: [1, 2, 3]. They can hold any mix of types — integers, strings, booleans, even other lists. An empty list is just [].

Slicing lists
Lists support the same slicing as strings: nums[1:4], nums[::-1]. Slicing always returns a new list — it never modifies the original.
List operations
+ concatenates two lists. * repeats a list. len() gives the count. in checks membership. sorted() returns a new sorted list without modifying the original (unlike .sort()).
Nested lists
Lists can contain other lists — this is how you represent grids and matrices. Access nested items with double indexing: matrix[0][1] gets row 0, column 1.
Analogy: A list is like a train — each car (element) has a numbered position, you can add or remove cars, and you can look at any car directly by its position number.

⭐
Fun fact: Python lists are actually dynamic arrays under the hood. When you .append() and the list runs out of space, Python automatically allocates a larger block of memory — roughly doubling the capacity. This is why appending is O(1) amortized.
