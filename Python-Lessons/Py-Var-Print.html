Lesson 1 — Variables & Print

Every program needs to store data and show output. In Python, you do this with variables and the print function — the two most fundamental tools you'll use in every program you ever write.

VARIABLES A variable is a named container that holds a value. You create one by writing a name, an equals sign, and the value: name = "Arman". The value can be changed later.
DATA TYPES Variables can hold different types of data. Strings are text in quotes ("hello"). Integers are whole numbers (17). Floats are decimal numbers (3.14). Booleans are True or False.
PRINT FUNCTION The print() function shows output on the screen. You pass it values to display, separated by commas: print("Hello", name).
NAMING RULES Variable names can contain letters, numbers, and underscores — but must start with a letter or underscore. They are case-sensitive: name and Name are different variables.
WHY VARIABLES MATTER Without variables, you'd have to retype values everywhere. Variables let you write code once and change a value in one place — making your programs flexible and clean.
Try It Yourself

Storing values in variables:

name = "Arman"
age = 17

print("Name:", name)
print("Age:", age)

Different data types:

username = "warrior_42"   # string
level = 5                 # integer
xp_per_lesson = 10.5      # float
is_logged_in = True       # boolean

print(username, level, xp_per_lesson, is_logged_in)

Updating a variable:

xp = 0
print("Starting XP:", xp)

xp = xp + 10
print("After lesson 1:", xp)

xp = xp + 10
print("After lesson 2:", xp)
