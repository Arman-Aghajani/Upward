Lesson 2 — Fonts

Typography is one of the most important parts of a website's design. Good font choices make text easy to read; bad ones make even great content frustrating. CSS gives you complete control over how text looks.

FONT FAMILY The font-family property sets the typeface. List multiple fonts as fallbacks: font-family: Arial, Helvetica, sans-serif; — the browser uses the first one available.
FONT SIZE Use font-size to control how big text is. Common units: px (fixed pixels), em (relative to parent), rem (relative to root).
FONT WEIGHT font-weight sets how thick the text is. Use names (normal, bold) or numbers from 100 (thin) to 900 (heavy).
FONT STYLE font-style: italic makes text slanted. Use sparingly for emphasis or quotes.
GOOGLE FONTS You can load custom fonts from Google Fonts. Add a <link> in the head, then use the font name in CSS like any other. That's how Upward uses "Press Start 2P" everywhere.
Try It Yourself

Basic font properties:

body {
  font-family: Arial, sans-serif;
  font-size: 16px;
}

h1 {
  font-size: 32px;
  font-weight: bold;
}

Italic and different weights:

.quote {
  font-style: italic;
  font-weight: 300;
}

.title {
  font-weight: 900;
}

Using Google Fonts:

<!-- in HTML head -->
<link href="https://fonts.googleapis.com/css2?
       family=Press+Start+2P" rel="stylesheet">

/* in CSS */
.gamer-text {
  font-family: 'Press Start 2P';
  font-size: 14px;
}
