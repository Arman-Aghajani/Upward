L6 Margin & Padding

Margin and padding control spacing. Margin pushes elements away from each other. Padding creates breathing room inside an element.

Shorthand syntax
4 values: margin: top right bottom left (clockwise). 2 values: margin: vertical horizontal. 1 value: all sides. margin: 16px 24px = 16px top/bottom, 24px left/right.
Auto margins for centering
margin: 0 auto centers a block element horizontally — but only works if the element has a defined width. Most common centering technique for containers.
Margin collapse
Vertical margins between two block elements collapse into one — the larger margin wins. p { margin: 20px } between two paragraphs = 20px gap, not 40px. This surprises beginners often.
Padding use cases
Padding gives clickable area to buttons. It spaces text from borders. Never use margin to add internal space — that is padding's job. Padding affects background color; margin is always transparent.
Analogy: Padding = the cushion inside a box. Margin = the space between boxes on a shelf. Both control spacing, but one is internal and one is external.

1<!DOCTYPE html>
2<html><head>
3  <style>
4    .container {
5      width: 300px; margin: 0 auto;

11    }
