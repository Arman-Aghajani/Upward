Lesson 6 — Positioning

The position property controls where an element sits on the page. By default everything flows top-to-bottom, but positioning lets you break out of that flow and place elements exactly where you want them.

STATIC The default. Elements follow the normal document flow. top, left, right, bottom have no effect.
RELATIVE The element stays in the flow, but you can nudge it from its normal spot using top, left, etc. It still takes up its original space.
ABSOLUTE Removes the element from the flow and places it relative to its nearest positioned ancestor. Other elements act like it isn't there.
FIXED Locks the element to the viewport — it stays in place even when you scroll. Perfect for navbars, chat bubbles, and back-to-top buttons.
Z-INDEX When elements overlap, z-index controls which one appears on top. Higher numbers stack above lower ones. Only works on positioned elements.
Try It Yourself

Relative positioning — nudging an element:

.badge {
  position: relative;
  top: -10px;
  left: 15px;
  background: gold;
  padding: 4px 8px;
}

Absolute positioning inside a parent:

.parent {
  position: relative;
  width: 200px;
  height: 120px;
  background: navy;
}

.corner {
  position: absolute;
  top: 8px;
  right: 8px;
  background: red;
  color: white;
  padding: 4px;
}

Fixed navbar that stays on scroll:

.navbar {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  background: black;
  color: white;
  padding: 10px;
  z-index: 100;
}
