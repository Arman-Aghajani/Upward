Lesson 1 — Colors

Colors bring a webpage to life. CSS gives you full control over the color of text, backgrounds, borders, and shadows — and there are several ways to specify exactly which color you want.

COLOR PROPERTY The color property changes the color of text inside an element.
BACKGROUND COLOR The background-color property fills the box of an element with a color — behind any text or images inside.
NAMED COLORS CSS has 140+ predefined color names: red, blue, tomato, navy, gold. Quick to write, but limited to those specific shades.
HEX COLORS Hex codes start with # followed by 6 digits. Example: #FFD700 is gold. Each pair controls red, green, and blue (00-FF). Most precise format.
RGB AND RGBA rgb(255, 215, 0) is the same as #FFD700. The rgba() version adds a fourth number for opacity (0 = invisible, 1 = solid). Useful for transparent overlays.
Try It Yourself

Named colors:

h1 { color: gold; }
p { color: white; }
body { background-color: navy; }

Hex codes for precise colors:

h1 { color: #FFD700; }
p { color: #00FF90; }
body { background-color: #0a0a4a; }

RGB and transparency with RGBA:

.box {
  background-color: rgb(255, 215, 0);
  color: rgba(255, 255, 255, 0.8);
  border: 2px solid rgba(0, 0, 0, 0.3);
}
