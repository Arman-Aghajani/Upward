Lesson 4 — Selectors

Selectors tell CSS which HTML elements to style. Without selectors, CSS doesn't know what to target. Mastering selectors is the key to writing clean, powerful stylesheets.

ELEMENT SELECTOR Select all elements of a tag by writing the tag name. Example: p targets every paragraph on the page.
CLASS SELECTOR Select elements by their class attribute using a dot. Example: .btn targets every element with class="btn". Use classes for reusable styles.
ID SELECTOR Select a unique element by its id attribute using a hash. Example: #header targets the one element with id="header". IDs must be unique per page.
DESCENDANT SELECTOR Combine selectors with a space to target nested elements. nav a targets every <a> inside a <nav>.
PSEUDO-CLASSES Special states activated by a colon. :hover applies when the mouse is over an element. :first-child targets the first child in a parent.
Try It Yourself

Element, class and ID:

p {
  color: gray;
}

.highlight {
  background: yellow;
}

#title {
  font-size: 32px;
  color: crimson;
}

Descendant and grouped selectors:

nav a {
  color: white;
  text-decoration: none;
}

h1, h2, h3 {
  font-family: Arial;
}

Pseudo-classes:

button:hover {
  background: gold;
  cursor: pointer;
}

li:first-child {
  font-weight: bold;
}
