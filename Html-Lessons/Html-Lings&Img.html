Lesson 3 — Links & Images

The web is built on connections. Links let users jump between pages, and images bring visual content to life. Together they're what makes the web feel alive.

ANCHOR TAG The <a> tag creates a hyperlink. The href attribute tells the browser where to go when clicked.
LINK TYPES Links can point to other websites (https://...), other pages on your site (about.html), sections of the same page (#section), or even open email apps (mailto:).
IMAGE TAG The <img> tag displays an image. It needs a src (where the image file is) and an alt (a text description for screen readers and broken images).
SELF-CLOSING Unlike most tags, <img> does not have a closing tag. It's self-contained — just one tag with attributes.
OPENING IN NEW TAB Add target="_blank" to a link to open it in a new browser tab instead of replacing the current page.
Try It Yourself

Basic link:

<a href="https://www.google.com">
  Visit Google
</a>

Link that opens in a new tab:

<a href="https://www.google.com" target="_blank">
  Open Google in new tab
</a>

Image with alt text:

<img src="https://via.placeholder.com/150"
     alt="placeholder image">

Image wrapped in a link (clickable image):

<a href="https://upward.com">
  <img src="logo.png" alt="Upward logo">
</a>
