L2 Headings &
Paragraphs

Headings and paragraphs are the backbone of any text on the web. Every article, blog post, and documentation page is built from these two elements.

Headings h1 to h6
HTML has 6 heading levels. <h1> is the biggest and most important — use it once per page for the main title. <h2> for sections, <h3> for sub-sections, and so on down to <h6>.
Paragraphs
The <p> tag wraps a block of text into a paragraph. The browser automatically adds spacing above and below each <p>. You don't need blank lines in your HTML — the tag handles it.
HTML ignores whitespace
Extra spaces, tabs, and blank lines in your HTML source are collapsed into a single space when rendered. Structure comes from tags, not from how you format your source code.
Block elements
Both headings and paragraphs are block elements — they each start on a new line and take up the full width available. You never need to manually add line breaks between them.
Analogy: Think of a textbook. <h1> is the book title, <h2> is the chapter name, <h3> is a section heading. <p> is the body text between those headings.

🎯 Task — Build a mini article
Create a mini article about any topic. Use one <h1> for the main title, one <h2> for a section, and at least two <p> paragraphs of content.
⭐
Fun fact: Search engines like Google give heavy weight to your <h1> tag when ranking pages. Every page should have exactly one <h1> — it tells Google what the page is about.
