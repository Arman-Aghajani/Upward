L3 Text Formatting
in HTML

HTML gives you tags to style and emphasize text directly in your markup — bold, italic, underline, and more. Some tags are purely visual; others carry semantic meaning.

Bold & Strong
<b> makes text visually bold. <strong> also makes it bold but tells the browser this text is important — search engines and screen readers notice the difference.
Italic & Emphasis
<i> renders text in italics. <em> also italicises it but signals emphasis. Use <em> when the word genuinely needs stress, <i> for things like book titles or foreign terms.
Other Formatting Tags
<u> underlines text. <s> draws a strikethrough (great for crossed-out prices). <mark> highlights text in yellow. <small> renders smaller text. <sub> and <sup> give subscript and superscript.
Inline vs Block
All text formatting tags are inline — they do not break onto a new line. They sit inside paragraphs and headings, changing only the portion they wrap.
Analogy: Think of <b> as a highlighter that just changes colour, and <strong> as a highlighter that also writes "IMPORTANT" in the margin. Same look, different meaning.

🎯 Task — Format a product description
Write a paragraph about any product. Use <strong> for the product name, <em> for a feature, <s> for the old price and <mark> on the new price.
⭐
Fun fact: The <blink> tag once made text flash on and off. It was so annoying that browsers removed support for it entirely. Always use formatting to help readers — not to torture them.
