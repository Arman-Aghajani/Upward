L14 Multimedia

HTML5 introduced native video and audio support — no plugins, no Flash, no third-party player needed. You can embed media directly into any page with a single tag.

The <video> element
<video src="clip.mp4" controls></video> embeds a video. Key attributes: controls shows the play/pause bar, autoplay starts immediately, loop repeats, muted silences it (required for autoplay in browsers), poster="thumb.jpg" shows a thumbnail before play.
The <audio> element
<audio src="song.mp3" controls></audio> works the same way for audio. Same attributes apply: controls, autoplay, loop, muted. Without controls, the element is invisible — useful for background music.
Multiple formats with <source>
Different browsers support different formats. Use <source> children to provide fallbacks: the browser picks the first format it can play. Common video: mp4, webm. Common audio: mp3, ogg. Add fallback text for very old browsers.
figure and figcaption
<figure> wraps self-contained media (image, video, diagram, code). <figcaption> inside it gives that media a semantic caption. Screen readers, Google, and other tools understand the caption belongs to that specific media element.
Analogy: <source> is like having the same film on DVD, Blu-ray, and streaming — you let the viewer's player choose whichever format it can handle, and the experience is the same.
