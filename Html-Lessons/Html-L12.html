L12 Head & Meta Tags

The <head> is invisible to users but critical to browsers, search engines, and social media. It is where you configure the page before any content is shown.

charset and viewport
<meta charset="UTF-8"> ensures all characters (including accents and emoji) render correctly. <meta name="viewport" content="width=device-width, initial-scale=1.0"> makes the page responsive on mobile. Both go in every page you ever build.
title and description
<title> sets the browser tab name and is the main SEO signal. <meta name="description" content="..."> is the short text Google shows under your link in search results. Keep it under 160 characters.
Linking CSS
<link rel="stylesheet" href="style.css"> connects an external CSS file. The rel attribute says what kind of resource it is. You can link multiple stylesheets — they all apply in order.
Open Graph basics
When someone shares your page on social media, platforms read Open Graph tags: <meta property="og:title">, <meta property="og:image">, <meta property="og:description">. Without them, the preview looks broken.
Analogy: The <head> is like the inside cover of a book — the reader never sees it, but it tells libraries, search engines, and publishers everything they need to know about the book.
index.html <head>
1<head>
2  <meta charset="UTF-8">
3  <meta name="viewport" content="width=device-width, initial-scale=1.0">
4  <title>My Portfolio</title>
5  <meta name="description" content="Developer portfolio by Alex">
6  <link rel="stylesheet" href="style.css">
7  <meta property="og:title" content="My Portfolio">
8  <meta property="og:image" content="preview.png">
9</head>

🎯 Task — Build a proper <head>
Write a complete HTML page with a proper <head>: include charset, viewport, a meaningful <title>, a meta description, a <link> to an imaginary style.css, and at least one og: meta tag. Add a simple <body> with a heading so you can preview it.
⭐
Fun fact: The viewport meta tag was invented by Apple for the original iPhone in 2007. Before it existed, mobile browsers would just zoom out to show the full desktop layout — making text tiny and unreadable. It became a standard a few years later.
