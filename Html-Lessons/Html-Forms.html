Lesson 5 — Forms & Inputs

Forms let users send information to a website — logging in, signing up, searching, submitting feedback. Every interactive website uses forms.

THE FORM TAG Wrap all input fields inside a <form> element. It groups inputs together and controls where the data is sent.
INPUT TYPES The <input> tag changes behavior based on its type attribute — text, password, email, number, checkbox, radio, date and more.
LABELS & PLACEHOLDERS Use <label> to describe what a field is for. Use placeholder to show hint text inside an empty input.
SELECT & TEXTAREA Use <select> with <option> tags for dropdowns. Use <textarea> for multi-line text input.
SUBMIT BUTTON A <button type="submit"> sends the form data. Without it, the user has no way to submit what they typed.
Try It Yourself

Simple login form:

<form>
  <label>Email:</label>
  <input type="email" placeholder="you@mail.com">

  <label>Password:</label>
  <input type="password">

  <button type="submit">Log In</button>
</form>

Different input types:

<input type="text" placeholder="Name">
<input type="number" placeholder="Age">
<input type="date">
<input type="checkbox"> Agree to terms

Dropdown and textarea:

<select>
  <option>Python</option>

</select>
