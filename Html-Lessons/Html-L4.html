L4 Links —
The <a> Tag

Links are what make the web a web. The anchor tag <a> lets you connect pages, jump to sections, open emails and download files — all with one element.

The href Attribute
<a href="https://example.com">Visit</a> — href is the destination. It can be an absolute URL (full web address), a relative path (another file on your site), or a fragment ID starting with #.
Opening in a New Tab
Add target="_blank" to open the link in a new browser tab. Always pair it with rel="noopener noreferrer" for security — it prevents the opened page from accessing your page.
Relative vs Absolute
Absolute: href="https://google.com" — goes anywhere on the web. Relative: href="about.html" — links to a file in the same folder. Relative links keep your site portable.
Special href Values
href="#section" jumps to an element with that ID on the same page. href="mailto:hi@example.com" opens an email client. href="tel:+40700000000" dials on mobile.
Analogy: An <a> tag is like a portal in a video game. The text you see is the door; the href is the coordinates of where it takes you.
