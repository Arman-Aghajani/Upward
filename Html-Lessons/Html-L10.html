L10 Block vs
Inline Elements

Every HTML element behaves as either block or inline. This is the most fundamental layout rule in HTML — understanding it unlocks how pages are structured.

Block Elements
A block element always starts on a new line and takes up the full width available. Examples: <div>, <p>, <h1>–<h6>, <ul>, <li>, <table>, <form>. Think of them as stacked boxes.
Inline Elements
An inline element flows within text — it does not break to a new line and only takes as much width as its content. Examples: <span>, <a>, <strong>, <em>, <img>, <code>.
<div> and <span>
<div> is a generic block container with no visual styling by default — a box you can group things in. <span> is a generic inline container. Both become useful once you add CSS classes.
CSS Can Change It
You can override any element's display type with CSS: display: block, display: inline, or display: inline-block (inline but respects width/height). This is how navigation links are styled as buttons.
Analogy: Block elements are like paragraphs in a book — each starts on its own line. Inline elements are like words within that paragraph — they flow side by side without breaking the sentence.
