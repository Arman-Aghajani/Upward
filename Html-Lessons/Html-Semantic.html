Lesson 6 — Semantic HTML

Semantic HTML means using tags that describe the meaning of the content, not just how it looks. Instead of wrapping everything in generic <div> tags, you use tags that tell browsers and search engines what each section actually is.

HEADER & FOOTER <header> holds the top of the page — logo, title, intro. <footer> holds the bottom — copyright, contact links, extra info.
NAV The <nav> tag wraps navigation links — menus, sidebars, breadcrumbs. Screen readers and search engines use it to find the site's main links.
MAIN <main> wraps the most important content of the page. Only one per page — it's the core content users came for.
SECTION & ARTICLE <section> groups related content together. <article> is for content that makes sense on its own — a blog post, news story, or forum comment.
WHY IT MATTERS Semantic HTML improves accessibility (screen readers can navigate better), SEO (search engines understand your content) and code readability (other developers know what each block is).
Try It Yourself

Non-semantic (old way):

<div id="header">
  <div id="nav">...</div>
</div>
<div id="main">
  <div class="post">...</div>
</div>
<div id="footer">...</div>

Semantic (modern way):

<header>
  <nav>...</nav>
</header>
<main>
  <article>...</article>
</main>
<footer>...</footer>

Full semantic page layout:

<header>
  <h1>Upward</h1>
  <nav>
    <a href="#">Home</a>
    <a href="#">Lessons</a>
  </nav>
</header>

<main>
  <section>
    <h2>Welcome</h2>
    <article>
      <h3>First Lesson</h3>
      <p>Start your journey...</p>
    </article>
  </section>
</main>

<footer>© 2026 Upward</footer>
