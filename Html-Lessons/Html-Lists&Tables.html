Lesson 4 — Lists & Tables

Lists group related items together. Tables display structured data in rows and columns. Both are essential for organizing content on a web page.

UNORDERED LIST Use <ul> for bullet-point lists where order doesn't matter. Each item goes inside <li> tags.
ORDERED LIST Use <ol> for numbered lists where order matters — like step-by-step instructions or rankings.
TABLE STRUCTURE A <table> contains rows <tr>. Each row has header cells <th> or data cells <td>.
WHEN TO USE WHICH Use lists for collections of related items. Use tables only for truly tabular data with rows and columns — not for layout.
Try It Yourself

Unordered list:

<ul>
  <li>Python</li>
  <li>HTML</li>
  <li>CSS</li>
</ul>

Ordered list:

<ol>
  <li>Wake up</li>
  <li>Learn code</li>
  <li>Rank up</li>
</ol>

Basic table:

<table border="1">
  <tr>
    <th>Rank</th>
    <th>XP</th>
  </tr>
  <tr>
    <td>E</td>
    <td>100</td>
  </tr>
  <tr>
    <td>D</td>
    <td>150</td>
  </tr>
</table>
