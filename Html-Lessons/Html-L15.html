L15 HTML5 Modern
Elements

HTML5 shipped a set of powerful native elements that replace things previously requiring JavaScript or plugins. These give you interactive UI, data visualisation, and dynamic content — all in pure HTML.

details and summary
<details> creates a collapsible section. <summary> is the always-visible clickable title. When the user clicks it, the rest of the content expands — a native accordion with zero JavaScript. Add the open attribute to start it expanded.
progress and meter
<progress value="70" max="100"> shows a loading-style bar. <meter value="6" min="0" max="10"> shows a gauge for a known range (like a score). Both render natively with OS-style styling and are accessible out of the box.
dialog
<dialog> is a native modal popup. Call dialog.showModal() in JavaScript to open it — it automatically traps focus and adds a backdrop. dialog.close() dismisses it. Before this, every modal was hand-built with CSS hacks.
canvas intro and datalist
<canvas> is a blank drawing surface you control with JavaScript — used for games, charts, and animations. <datalist> pairs with an <input list="..."> to give the user autocomplete suggestions while still allowing free typing.
Analogy: These HTML5 elements are like power tools that arrived with the house — you do not need to build a drill from scratch when one is already in the toolbox, native and ready to use.
